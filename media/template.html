What is this?

Quickpanel is your command center for terminal commands, multi-step processes, and file templates.

Favorites

Star any terminal command, process, or file with ☆. Favorites appear as one-click run buttons at the top. Unstar to remove them. Favorites are not edited in place — edit them in their category.

Single-line terminal commands

Single-line shell commands (e.g. npm run dev or npx skills add …). Run with one click — no confirm.

Multi-step processes

Multi-step workflows: terminal commands and file creates, in order. Expand steps to edit. Only Run on the whole process asks for confirm.

File creation

File templates. Run creates that file in your workspace folder immediately.

Drag & drop

Use the handle on the right to reorder items within a category.
