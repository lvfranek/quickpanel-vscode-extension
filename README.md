⚡ Quickpanel
A powerful VS Code extension that brings shortcuts, notes, file templates and multi-step processes right into your editor. Stay productive without leaving your workflow.

⌨️ Technologies

* TypeScript
* VS Code Extension API
* Webview Panel
* HTML / CSS / JavaScript

🚀 Features

* Four modern tabs: Shortcuts, Notes, Files, Processes & Skills
* Full drag & drop reordering for items and process steps
* Create and manage personal shortcuts and rich markdown notes
* File templates that generate real files in your workspace
* Multi-step processes & skills (run commands + create files sequentially)
* Custom confirm dialogs and accordion-style process cards
* Persistent state across VS Code sessions
