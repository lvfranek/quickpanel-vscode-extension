# ⚡ Quickpanel
![Quickpanel demo](media/quickpanel-gif-1.gif)

### Run terminal commands and create files twice as fast ⚡

- Define your own terminal commands that you can run within one click (for example npm run dev or for installing an AI skill)
- Define a set of terminal commands and create a whole process, for example for creating a project, that can be run within 1 click.
- Define files that you want to create with one click (for example an AGENTS.md with pre filled instructions for the AI)

- There are presets when you first install the extension. You can decide to remove or edit any preset or add your own.

---

### How to open ✅
- Click Quickpanel on the bottom right of VS Code.

---

###  Pre-loaded presets
- Terminal: `npm run dev` (favorited), install React best-practices skill
- Process: Create React App (Vite + install + `.env`)
- Files: `README.md`, `AGENTS.md`, `.gitignore`, `.env`

You can remove or edit any of these at any time.
